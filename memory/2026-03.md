# Memory — 2026-03

## 2026-03-30: llama-rocm froze the server
ROCm backend on Strix Halo (gfx1151) hung llama-server at tensor finalization during load. Documented issues: sched_reserve deadlock (ROCm#6027), KV cache dumped to system RAM (llama.cpp#18011), MUT_MAL crashes (ROCm#5534). Conclusion: Vulkan is the only reliable backend here; unified-memory rules (never two model instances, always `docker ps` between stops/starts) added to context/llm.md.
